# samurai-links

Página de links da bio do Instagram @samuraidojuridico, publicada em https://links.samurailab.com.br pelo GitHub Pages.

- Tudo entra por pull request ligado a uma issue.
- O portão (`.github/workflows/portao.yml`) confere HTML, travessão, segredo e peso das imagens antes do merge.
- Para ver no computador: `python -m http.server 8787` nesta pasta e abrir http://127.0.0.1:8787/.
